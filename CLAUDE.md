# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Layout

The workspace root (`Dashboard_fig/`) holds a single Next.js app in `dashboard/`. Every npm command below must be run from `dashboard/`, not from the root.

`dashboard/CLAUDE.md` only contains `@AGENTS.md`, which pulls in a block auto-generated by `next dev`. That block is rewritten on every dev run; commit it with your work rather than trying to remove it.

Git note: this folder is not its own repository. `git rev-parse --show-toplevel` resolves to the user's home directory, so do not run commits from here unless the user explicitly asks and confirms the target repo.

## Commands

```bash
cd dashboard
npm run dev     # next dev (Turbopack) on http://localhost:3000
npm run build   # next build
npm run start   # serve the production build
npm run lint    # eslint (flat config, next core-web-vitals + typescript)
```

There is no test runner configured. Type-checking happens through `next build`; for a standalone check use `npx tsc --noEmit` from `dashboard/`.

## Stack and conventions

- **Next.js 16.3 App Router** with React 19 and TypeScript `strict`. This Next version has breaking changes versus older training data. Before writing framework code, read the relevant guide under `dashboard/node_modules/next/dist/docs/` and respect deprecation notices.
- **Route typing**: layouts use the generated `LayoutProps<"/">` helper (from `.next/types`, included via `tsconfig.json`) instead of hand-written prop types. Follow the same pattern for new layouts and pages.
- **Tailwind CSS v4** via `@tailwindcss/postcss`. There is no `tailwind.config.*`; the theme lives in `src/app/globals.css` using `@import "tailwindcss"` and `@theme inline`. Add design tokens there as CSS variables, then map them into `@theme inline` so Tailwind utilities pick them up.
- **Fonts**: Geist and Geist Mono are loaded in `src/app/layout.tsx` with `next/font/google` and exposed as `--font-geist-sans` / `--font-geist-mono`, which `globals.css` maps to `--font-sans` / `--font-mono`.
- **Path alias**: `@/*` maps to `dashboard/src/*`.
- `src/app/page.tsx` and the `layout.tsx` metadata are still the create-next-app placeholders and are expected to be replaced.
